# Giant object edit — instruction and prompt

One page for ChatGPT. Read the steps, then copy the prompt at the bottom.

## How to use it

1. Open ChatGPT. Use a model that can edit images, not a text-only chat.
2. Find a good photo of yourself. You want clear light, a face that is easy to see, and a sharp picture. Avoid heavy filters, motion blur, a face cut off by the frame, and sunglasses that hide the eyes. If the object will sit in your hands, the hands should be visible too.
3. Find the object you want next to you. Download a clear reference photo. Add it from all sides if you can (front, side, heel, sole, logo), or from one side only if that is all you have. One clean view is enough. Several views keep the shape, color, and logo closer to the real object.
4. In one message, upload your photo first, then the object photos. Do not send the photo and the prompt in separate turns.
5. Copy the prompt below. The object line is already set for this example: a tan suede Puma sneaker with a white formstrip, cream sole, gold heel logo, and a round suede tag. Change that line if you use a different object.
6. Paste the prompt under the images and send. If the face changes, or the object looks pasted on, reply: keep the person and the original photo unchanged, and only adjust the object's scale, angle, light, and shadows.

Example used with this prompt: a night beach photo, face visible, full pose, plus Puma sneaker photos from the front, both sides, heel, top, and sole.
